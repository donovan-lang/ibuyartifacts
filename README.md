# iBuyArtifacts

## Overview
iBuyArtifacts is a web application for browsing, appraising, and selling artifacts. The platform connects collectors with expert appraisals and marketplace features for antiquities and collectibles.

## Setup
1. Install Python dependencies: `pip install -r requirements.txt`
2. Run the application: `python fetch_artifacts.py`
3. Open `http://localhost:5000` in your browser (or configured port)

## Tech Stack
- **Backend**: Python
- **Frontend**: HTML5, CSS, JavaScript
- **Data**: JSON (artifacts_data.json)
- **Pages**: Index, Gallery, Appraisal, News, Marketplace
